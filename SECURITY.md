# Security reporting

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/vickyteke/cedari-agent-template/security/advisories/new). Never submit real customer data, service credentials or exploit material to public issues.

Operators own Supabase projects, secret rotation, AI/email budgets and deployment settings. A template fork requires its own security review, dependency monitoring, legal/support URLs and privacy disclosures before customer use.
