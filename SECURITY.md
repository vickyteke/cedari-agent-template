# Security reporting

Report vulnerabilities privately to the maintainer contact configured by the repository owner before public publication. This local template has not chosen a public reporting mailbox yet. Never submit real customer data, service credentials or exploit material to public issues. Once the repository exists, enable GitHub private vulnerability reporting and document the contact here.

Operators own Supabase projects, secret rotation, AI/email budgets and deployment settings. A template fork requires its own security review, dependency monitoring, legal/support URLs and privacy disclosures before customer use.
